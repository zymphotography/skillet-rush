Skillet Rush — run the kitchen. Orders come in on the board; pick up ingredients from the bins along the counter, build each dish on the plate in the middle, and ring the bell at the serving window before the order goes cold. A 120-second shift, 3 hearts, and a combo bonus for serving dish after dish without a mistake. Five dishes on the menu, orders arrive faster as you level up.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

Play with the keyboard (← → or A D to move, Space to pick up / drop / serve / trash, P to pause) or the mouse (steer by moving, click to act). No build step, no network: `game/` is plain static files.

Screenshots are staged from the real game with `?shot=start|play|serve|end&seed=1` (see `shots.json`).
